# interior-models-stores

Shard of https://github.com/iandamai720-cmyk/interior-models with the store-product data (PL / US / TH furniture stores).
Served from GitHub Pages at https://iandamai720-cmyk.github.io/interior-models-stores/:

| Path | Content |
|---|---|
| `/api/store-products/{id}.json` | full store-product record (price + currency, dimensions, product link, images = links to the store, similar 3D model) |
| `/api/store-products/category/{category}.json`, `/api/store-products/room/{room}.json` | store products by category / room |
| `/api/store/{store}.json`, `/api/store/{store}/{category}.json` | products per store (and per store × category) |
| `/api/stores.json`, `/api/index.json` | store summary (products, with price, country) and endpoint index |

The main site keeps `catalog.json` (all assets, incl. store products), `/api/store-products.json` and `/api/country/{pl,us,th}.json`; their `api_url` fields point here.
Product photos are not copied – `image_url` / `preview_url` link to the store (data/images © the store, link only).
All new stores (Global House, Castorama, Leroy Merlin, US stores …) are added here by `tools/merge_browser.py --catalog --push`.
Generated by `scripts/build_api2.py` in the main repo.
